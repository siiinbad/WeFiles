# WeFiles brand asset

`source.png` is the user-supplied logo copied unchanged.
`logo.svg` frames the original embedded bitmap in a square viewBox, reducing
empty outer margins without redrawing, recoloring, stretching or cutting into
the substantive logo artwork. It is self-contained so it also works as a favicon.
One cached asset is shared across header and page placements.

Palette sampled from the logo:

- Lime: `#C1FF72` — primary actions and selected navigation.
- Green: `#7ED957` — brand accents.
- Fresh green: `#50D05C` — secondary illustration accents.
- Black and white — wordmarks, frames and surfaces.

Deeper green is used for small text on light backgrounds to preserve contrast.
Logo white backing remains intact in both themes. UI corners stay small and
spacing follows the existing sharp design system.
